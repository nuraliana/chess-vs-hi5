Cara main jarak jauh

Halaman ini tidak menyimpan langkah di server — papan ada di browser masing-masing. Caranya: mainkan langkahmu di sini, lalu tekan Salin PGN dan kirim PGN-nya ke lawan lewat chat. Lawan menempel PGN itu di kotak "Lanjutkan game dari PGN", tekan Muat PGN, lalu memainkan balasannya — dan mengirim PGN terbaru kembali. Begitu terus sampai ada yang menang. Promosi pion otomatis jadi Menteri (Queen). Hasil game yang selesai bisa disimpan sebagai file PGN di folder matches/ repo ini.
